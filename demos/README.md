# dbt_jev demo reel

The X-ready reel and GitHub README GIF are generated by
[Charmbracelet VHS](https://github.com/charmbracelet/vhs) from
`dbt_jev_x_demo.tape`.

The reel deterministically replays four classifications from a validated
OpenRouter-backed dbt run. It keeps the main story focused on turning messy
tool-call narratives into `expected`, `unexpected`, or `unknown`; the other
macros appear only on the end card. The replay keeps the marketing asset stable,
secret-free, and free to re-render without spending API credits.

Render from the repository root:

```bash
docker run --rm -v "$PWD/demos:/vhs/demos" ghcr.io/charmbracelet/vhs \
  demos/dbt_jev_x_demo.tape

ffmpeg -y -i demos/dbt_jev_x_demo_vhs_source.mp4 \
  -vf "tpad=stop_mode=clone:stop_duration=1.5,fps=30,format=yuv420p" \
  -c:v libx264 -preset slow -crf 18 -movflags +faststart -an \
  demos/dbt_jev_x_demo.mp4
```

Only the secret-free `demos/` directory is mounted into the renderer. The output
is a 1280×720 MP4, an inline README GIF, and PNG cover and end-card frames. The
final FFmpeg pass moves MP4 metadata to the front for reliable web playback and
adds a clear end hold.
